# 孤儿文件与死代码审计（2026-11-06）

> 目的：抓「代码在、入口没接」的哑火 —— 这是本项目最贵的教训（旧代码标着「实测通过」但有隐形逻辑 bug）。
> 方法：**不看文件名猜类型名**（踩过：`CloudBackupView.swift` 里其实是 `CloudBackupSheet`），
> 而是解析每个文件的顶层类型 + extension 目标 + 方法名，再跨全仓 grep 真实引用。

---

## 一、审计口径（重要，避免假阳性）

| 判据 | 说明 |
|---|---|
| **主类型引用** | 取文件内**第一个非 private 顶层类型**，跨文件 grep |
| **extension 文件** | `extension Store` 类文件不算孤儿 —— 方法挂在 Store 上，按**方法名**逐个查 |
| **辅助类型** | `private struct` / `fileprivate` 只在本文件用，不算孤儿 |
| **内部工具函数** | 被同文件其他函数调用的（如 `Self.xxx()`）不算孤儿 |

**第一版脚本错在哪**：按「文件名 == 类型名」查，把 `CloudBackupView` / `CustomProxySettings` / `SettingsDiagnostics` / `SettingsContributors` 误判成孤儿 —— 它们的真实类型是 `CloudBackupSheet` / `ProxySettingsView` / `LicensesView`+`DiagnosticsView` / `ContributorsSection`，全部有入口。

## 七、D-03 遗留的死脚本（2026-11-06 第 7 轮清理）

### 怎么发现的

核对 manifest「已丢弃」条目时，反向查了「被丢弃的东西是不是真的不在了」。
F-65 标「本地站点脚本（已丢弃）→ 见 02 D-03」，但文件还在。

### 判定依据（关键在 `LiteSites.script(for:)`）

```swift
static func script(for api: String) -> URL? {
    guard api.hasPrefix("csp_"), let entry = enabled[String(api.dropFirst(4))] else { return nil }
    if entry.script.hasPrefix("https://") { return URL(string: entry.script) }   // ← 走云端
    return URL(string: "assets://sites/" + entry.script)                         // ← 才读本地
}
```

只有 `index.json` 里登记的、且 `script` **不以 https 开头**的条目，才会去读本地 `.js`。
所以「磁盘上有 .js」≠「这个脚本会被加载」。

### 清掉的 9 个（共 ~117 KB，全部通过 `.copy("ScriptAssets")` 打进 App 包）

| 文件 | 为什么是死的 |
|---|---|
| `sites/Hema.js` / `Hongguo.js` / `Xifan.js` | `index.json` 的 classes 里**没有这三个 key**，永不查表 |
| `sites/hongguo/*`（6 个：LICENSE / NOTICE / app-source / crypto / playback-device / sm3） | 只在 `Hongguo.js` 内部用，而 `Hongguo.js` 本身不被加载 |
| `sites/Bili.js` | `index.json` 的 `Bili.script` 是 `https://.../bili.js`（云端），本地文件走不到 |

### 必须留下的（差点误删）

| 文件 | 被其他脚本 import |
|---|---|
| `_lite.js` | 30 次 |
| `_bridge.js` | 5 次 |
| `_fty.js` | 3 次 |

这三个不在 `index.json` 里，但它们是共享库 —— **判据不能只看 index.json**。

> 另一个差点误判的：`TVBoxProbe/main.swift` 里有 `--hongguo-check`，看着像在引用 `sites/hongguo/`。
> 实际它用的是上游 `Sources/TVCore/HongguoStreams.swift`（Swift 实现），跟那些 `.js` 无关。

### 清理后的恒等式（可复跑的判据）

```
index.json 本地引用 45 个 → 文件全部存在（缺 0）
磁盘上有但 index 不引用 3 个 → 全部是被 import 的共享库（死文件 0）
```
