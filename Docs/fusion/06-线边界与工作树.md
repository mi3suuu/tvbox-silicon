## 验收门（每条线自查，缺一不算完成）

```bash
# 1) TVCore 编译（最快）
swift build --package-path Packages/TVCore --target TVCore 2>&1 | tail -3

# 2) macOS App 编译
xcodegen generate --spec project.yml >/dev/null
xcodebuild -project TVBox.xcodeproj -scheme TVBox-macOS -configuration Debug \
  -derivedDataPath build/DD-line build 2>&1 | tail -3

# 3) 相关单测
swift test --package-path Packages/TVCore --filter "<你的模块关键字>" 2>&1 | tail -5
```

**已知基线失败（不算你的锅）**：`JavaHostVersionTests`、`FeedbackAttachmentsTests` —— 在纯上游 `fusion/base` 上同样失败（仓库布局问题）。
