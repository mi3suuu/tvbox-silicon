⚠️ 两个坑，都是实测踩过的：
1. **不能用 `otool -s` 直接喂 xxd**。它输出的是 4 字节分组的十六进制列，`cut -f2` 只取第一列，拼出来的字节流是乱的（当时的症状：`tr` 报 `Illegal byte sequence`，解出来的类名像 `AAWBelpparTtoCkcxetnirBtPegdivor` 这种回文）。必须把所有十六进制列拼起来或直接 `dd` 按 file offset 取。
2. **中文字符串不在 `.strings` 里**。`zh-Hans.lproj` 只有 87 个 `BBPlayerCommon` 之类的模块化文件，播放器的设置面板文案全部硬编码在 `__cstring` 中。要拿 UI 文案只能 `strings` + 定位区域。

## 7. 三个 QA 持久化的坑（都踩过并已修）

1. **`-qaBiliSkin` 写在 `QALaunch.start` 的 `guard` 之后就被跳过**。那个 guard 要求 section / page / qaPlay / qaDownload / qaPlayLive / qaPlayURL 至少一个非空，换皮参数不属于其中任何一个。第一版截图和完全不传参数一模一样，就是这个原因。
2. **`watchFullScreen` 只写不清**，截过一次全屏之后每次启动都进全屏，而全屏控件 4 秒后自动收 → 连续三张截图都是同一块纯色（9,11,13），看着像「三态全都没生效」。
3. **`qaBiliOpenSettings` 只写不清**，把双列与全屏两张图都盖成同一张设置面板。

统一规则：**QA 参数转写的持久键，传了就写，没传就移除/置回默认**。
