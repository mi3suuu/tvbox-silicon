## 2. 播放设置面板（`bbplayer_playersetting_*`）—— 这决定弹窗内容

### 倍速七档（实测 4 个已确认）
```
speed05   speed075  speed10  speed125  speed15  speed20  speed30
```
→ 0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 2.0 / 3.0，**七档，与截图一致**

### 播放模式（四态，与之前推断吻合）
```
actionloop      ← 循环播放
actionnext      ← 自动连播（下一集）
actionnextloop  ← 连播+循环
actionquit      ← 播完退出
```

### 画面比例（五种！我们只有一个开关）

```
ratio4_3            ← 4:3

```
