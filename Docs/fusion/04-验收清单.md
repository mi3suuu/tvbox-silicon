## A. 画风与 UI 一致性（V1-ui）

### A1 设计 token
| # | 检查项 | 判定标准 |
|---|---|---|
| A1-1 | 间距一律走 token | `grep -rn "padding(\.*16)\|spacing: 16" App/` 命中的裸数值，是否为有意的固定尺寸（图标/行高）而非布局间距 |
| A1-2 | 圆角走 `Radius.*` | 无裸 `.cornerRadius(8)` / `RoundedRectangle(cornerRadius: 12)` 之类散值（除非上游原有） |
| A1-3 | 字号走 `Brand.*` 或系统语义字号 | 无裸 `.system(size: 17)` 散值 |
| A1-4 | 颜色走语义色 | 无裸 `Color(red:...)` 直接用在正文；品牌色集中在 `Brand` / `GlassKit` |
| A1-5 | 深浅色都成立 | 每个二开新增视图都有 `Color(light:dark:)` 或系统语义色，深色模式下不出现白底白字 |

### A2 视觉层级
| # | 检查项 |
|---|---|
| A2-1 | 每个页面有明确的主标题 / 次标题 / 正文三级层次 |
| A2-2 | 主操作按钮视觉权重高于次要操作（不是全部同款玻璃球） |
| A2-3 | 列表项左对齐基线一致（图标列宽固定） |
| A2-4 | 分组之间有间距差（组内紧、组间松），不是均匀 padding |

### A3 状态齐全
| # | 检查项 |
|---|---|
| A3-1 | 每个异步页面有 loading 态（骨架屏或进度） |
| A3-2 | 每个列表有空态（不是白屏） |
| A3-3 | 每个网络页面有错误态 + 重试入口 |
| A3-4 | 破坏性操作有二次确认（删除保险库 / 清空缓存 / 删除环境） |

### A4 三平台适配
| # | 检查项 |
|---|---|
| A4-1 | tvOS 无 iOS-only 控件（`DisclosureGroup`、拖拽、`onHover`、`navigationBarBackButtonHidden`） |
| A4-2 | macOS 无 iOS-only API（`UIKit`、`safeAreaInset(edge:.bottom)` 之类） |
| A4-3 | 所有 `.onHover` / `hoverEffect` 都在 `#if !os(tvOS)` 内 |
| A4-4 | 触摸目标 ≥ 44pt（iOS）/ ≥ 66pt（tvOS 焦点） |

### A5 图标与文案
| # | 检查项 |
|---|---|
| A5-1 | 图标统一用 SF Symbols，不混 emoji / 自定义图片 |
| A5-2 | 二开新增文案全部走 `L10n.text(...)`，无裸中文字符串 |
| A5-3 | 四语言 key 齐全（en / ja / zh-Hans / zh-Hant） |
| A5-4 | 品牌名统一 Mi3s（技术标识 `yingxia://`、bundle id 不动） |

## B. 逻辑接线完整性（V2-wiring）

### B1 入口可达
| # | 检查项 | 判定标准 |
|---|---|---|
| B1-1 | 每个二开 View 都有真实入口 | 从 RootView / SettingsView / PlayerView 出发能点到；`grep -rn "PrivacyVaultView(" App/` 必须命中调用点 |
| B1-2 | 每个二开功能开关都能生效 | 开关写 `@AppStorage` 或 `Store`，且**读它的地方真的存在** |
| B1-3 | 没有孤儿文件 | 每个二开新增 `.swift` 至少被引用一次（`grep -rn "TypeName" App Sources` 命中 ≥2 处：定义 + 使用） |
| B1-4 | 没有死代码 | 无 `// TODO: 接线`、无 `_ = ` 占位、无永远为 false 的条件 |

### B2 数据流真实
| # | 检查项 |
|---|---|
| B2-1 | 每个 store 的写操作有对应的读路径（写进 `@AppStorage` 的 key，别处真读） |
| B2-2 | 环境隔离：`subscriptions` / `favorites` / `history` 都按 `environmentID` 过滤（无一处漏） |
| B2-3 | 隐私保险库：`visibleFavorites` / `visibleHistory` 是**唯一**对外出口，没有别处直接读裸数据 |
| B2-4 | 备份恢复：导出→导入 往返后，订阅/收藏/历史/设置四项都还原 |

### B3 上游能力未被压坏
| # | 检查项 |
|---|---|
| B3-1 | Manga 分区可用（订阅 Venera 源 → 分区出现 → 能读） |
| B3-2 | PlayerEpisodes（TMDB 剧照选集）入口在播放器菜单里 |
| B3-3 | LiveReopen 与我方 `recoverLiveAfterDrop` **两条路径都在**（丢包 + 时长） |
| B3-4 | 字幕：上游 `SubtitleStyle` 渲染 + 我方 `SubtitleTrack`/`SubtitleTranslator` 数据源都通 |
| B3-5 | 音乐 Liked Songs（上游 #523）与我方音乐迷你播放器不打架 |
