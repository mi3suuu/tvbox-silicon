# 全屏播放「画质」弹出框 —— 唯一基准款式

用户指定：以**画质弹出框**为基准款式，其余按钮沿用同一款式。

## 实测（竖屏全屏 466×678，OCR 归一化 → pt）

| 元素 | 归一化 y | x | 换算 pt（×678 / ×466） |
|---|---|---|---|
| `Resolution`（标题） | 0.594 | 0.034 | y≈403，x≈16 |
| `Advanced Settings >` | 0.596 | 0.706 | y≈404，x≈329（右对齐） |
| `Auto (720P HD)` | 0.667 | 0.065 | y≈452，x≈30 |
| `720P HD` | 0.759 | 0.065 | y≈515 |
| `480P SD` | 0.848 | 0.065 | y≈575 |
| `360P Smooth` | 0.940 | 0.065 | y≈637 |

### 款式特征（这是要统一的款式）

1. **从底部升起的面板**，不是右侧窄条
2. 上沿 y≈0.594 → **约 403pt**（屏高 678 的 59.4%），即面板占**下方 40.6%**
3. **标题行左右分置**：左边 `Resolution`，右边 `Advanced Settings >`（可点）
4. **选项纵向等距排列**，行距 ≈ **60~62pt**（0.667→0.759→0.848→0.940，Δ≈0.09×678≈61）
5. 选项**左对齐**，x≈30pt，缩进约 14pt
6. 深色底 `#212326`（与全屏弹窗同色）

## 横屏对应实测（678×466）

横屏行距 **62pt**（130→192→254→316），与竖屏 61 一致。
横屏宽度 **208pt**（454→662），贴右缘。

## 统一款式定义

```
┌─────────────────────────────────────┐
│ 标题                    Advanced >  │  ← 标题行，左右分置
├─────────────────────────────────────┤
│ 选项 1                              │  ← 行高 54~62，左对齐 x=30
│ 选项 2                              │
│ 选项 3                              │
│ 选项 4                              │
└─────────────────────────────────────┘
底色 #212326
竖屏：底部升起，占下方 ~40.6%，整宽
横屏：右侧滑出，宽 208pt，贴右缘
```

## 四个按钮套用此款式

| 按钮 | 标题 | 选项 |
|---|---|---|
| Subtitles | `Subtitles` | Off / 中文 /（Large Subtitles 开关行） |
| Episodes | `Episodes` | 选集列表（标题+日期+时长，量大可滚） |
| Speed | `Speed` | 3.0/2.0/1.5/1.25/1.0/0.75/0.5（**降序**，实测） |
| Auto（画质） | `Resolution` | Auto(720P HD)/720P HD/480P SD/360P Smooth |
