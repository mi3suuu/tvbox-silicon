## 2. 判负分层纪律（下结论前先自查）

1. **验证定式**：不默认「必须真机才能验」。编译通过 + 单测通过 + 静态接线审计（grep 调用点）三件套就能定「接上了没」。
2. **能力定式**：不默认「必须与上游逐字一致」。上游实现可用但缺我方能力时，用 extension 补，不重写。
3. **链路定式**：不默认「要么全接要么全丢」。允许「接数据层、不接 UI 层」这类分层结论，但**必须写进 `02-未纳入清单.md`**。

## 3. 逆向排障速查（本仓库高频坑）

| 现象 | 根因 | 破法 |
|---|---|---|
| `invalid redeclaration of 'Xxx'` | 我方独立文件与上游 `GlassKit.swift` 里的同名类型撞车 | 我方那个类型改名为 `Mi3sXxx`，或删我方版改用上游 |
| `ambiguous use of 'Brand'` | 同上，`Brand`/`Layout`/`Pill` 上游都在 `GlassKit.swift` | 优先删我方 `App/DesignSystem/Tokens/*`，改用上游 view modifier |
| `value of type 'Store' has no member 'xxx'` | 我方 View 引用了我方 Store 的独有成员，但 Store 是 L2 我方版还没接 | 先确认 `App/Store.swift` 是我方版，再补成员（M4） |
| `switch must be exhaustive` | 上游新增了 enum case（如 `comicSources`） | 加分支，**不要**写 `default` |
| tvOS 编译失败 | 用了 iOS-only API（`DisclosureGroup`、拖拽、`onHover`） | 加 `#if !os(tvOS)` |
| macOS 编译失败 | 用了 iOS-only API（`UIKit`、`navigationBarBackButtonHidden`） | 加 `#if os(iOS)` |
