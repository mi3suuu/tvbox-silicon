## 4. 明确区分：像素实测 vs 视觉模型

**像素实测（可作准）**
- 所有表格里的 x/y/w/h：由 `PIL` 读原始像素，按 `>110` 亮墨迹阈值或列方差阈值求 bbox，再 ÷3 转 pt。
- 胶囊/面板边界：用「胶囊带 vs 其上方 40px 带」的均值差 `>3` 判上下沿。
- 文字内容：Apple Vision OCR（`VNRecognizeTextRequest`，zh-Hans+en-US，`usesLanguageCorrection=false`）。

**视觉模型描述（仅用于「这是什么控件」的定性判读，不作坐标依据）**
- 视觉模型多次把横屏截图读成「竖屏 + 文字竖排」，并把不存在的按钮（点赞/下载/分享三键、底部三圆形图标）说成存在 —— 这些**已被像素否决**。
- 视觉模型给出的任何坐标一律**未采用**。

## 6. 复现命令（可复核）

```bash
# 1) 方向判定：对每张图跑 0°/90° OCR，比较「宽>高」文本框数
/tmp/ocrtool/ocr "<png>" 0    # 原生
/tmp/ocrtool/ocr "<png>" 90   # 旋转 90°

# 2) 正立画布（1–6 需旋转，7–9 不需）
python3 -c "from PIL import Image;Image.open(p).rotate(90,expand=True).save(o)"

# 3) 复算任意 bbox（÷3 得 pt）
python3 -c "import numpy as np;from PIL import Image;g=np.asarray(Image.open(p).convert('L')).astype(float);..."
```

**比例口径**：`x%屏宽 = x / 951`（Form A）或 `x / 669`（Form B）；`y%屏高 = y / 669`（Form A）或 `y / 951`（Form B）。全部保留 5 位小数（任务书要求 3 位，此处给足精度便于换算）。
