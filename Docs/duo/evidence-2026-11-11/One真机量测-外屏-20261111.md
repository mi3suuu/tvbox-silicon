## 0. 量测方法（先说清可信度来源）

视觉模型在本轮**全部后端不可用**（`VISION_BACKEND_UNAVAILABLE_THIS_TURN`，deepseek-v4-flash-vision-exp 被 Host 判为 text-only，ovh Qwen3.5/VL-72B/3.6 全部 429/超时）。因此**坐标一律由 PIL/numpy 像素计算得出**，视觉模型只在少数紧裁小图上用于文字转录（`vision_ocr`，成功 6 次：标题、合集、回放、元信息 2 行、继续播放）。

四类像素证据：

1. **行/列亮度剖面**：`row mean / p95 / max / count(>200)`，定位水平分带。
2. **局部对比度墨迹**：`g - GaussianBlur(g, r=45~80)` 阈值 12~22，把「控件」与「海报液态模糊背景」分离（背景是低频渐变，控件是高频墨迹，此法有效）。
3. **亮墨迹连通域**（BFS 8-邻域，minpix 30~400）求 bbox。
4. **★帧间差分（决定性证据）**：同一会话相隔 95 秒的两帧做 `|Δ|`，只有**真实视频画面**在变，静态 UI 恒为 0。这是本次唯一能无歧义切出播放器矩形的判据。

## 5. ★右侧竖带 x=1098..1397px（100.000pt 宽）不是 App 内容

这条 100.000pt 宽的竖带极易被误当成 App 的右侧面板，必须在复刻时**排除**。判定证据：

| 证据 | 数值 |
|---|---|
| 硬竖边 | x=1097 → 0，x=1098 → 54~70，**无过渡**；4 张图 y=129..1632px 全程稳定 |
| **帧差为零** | 图 10 vs 图 11 在该区 `mean|Δ| = 0.153`（左侧 App 列是 23.018）。视频在播时它**一动不动** |
| 只有 1016 个像素在变 | 集中在 y 260..342, x 1201..1305 —— 恰好是那个时钟字形的位置（时钟数字从 8:32 变 8:33） |
| 与视频模糊延伸无关 | `corr(blur(video) 行均值, 该带行均值) = −0.348`（负相关，不是同一画面） |
| 与主列不同屏幕 | 主列 y=129px 就出现首个墨迹；该带的首个墨迹在 **y=260px**。纵向基准差 131px |
| 与主列不构成缩放副本 | `corr(左列缩放至300px宽, 该带) = −0.082`；`corr(整图压扁, 该带) = −0.032` |

带内含：一枚**粗体时间字形簇**（x1202..1304, y260..295px = 400.667..434.667 × 86.667..98.333pt，亮>200，fill 0.31，逐像素在 10/11 间字形相同仅个别数字变），以及若干淡色图标（y566..622、y742..807px）。

**⇒ 这是另一块 artboard/另一台设备屏幕的残片（很可能是量测工具的多画板导出），不属于 466×678 cover 屏幕。**
**复刻时坐标应全部以 x∈[0, 1098px] = [0, 366.000pt] 为准；若按 466pt 满宽布局会整体错位 100pt。**
等价地：内容列宽 **350.000pt**（扣 16pt leading 后可用 334.000pt）。

## 8. 数据可复现性

- 全部 px 数值来自 `PIL` 读原始 PNG + `numpy` 计算，无缩放、无重采样（除展示用缩略图）。
- 关键阈值：墨迹 `g − GaussianBlur(g, r=45) > 20`；连通域 `minpix=120`（大字）/ `400`（胶囊）；帧差 `|Δ|>3`。
- 基准校验脚本断言：`1398/3 == 466.0` 且 `2034/3 == 678.0`（精确整除，故 px/3 无损）。
- 未做任何插值外推：表中每个 bbox 都是实测连通域或实测带边界。
