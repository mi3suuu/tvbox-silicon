## 二、逐参数核对（我方 vs 真 One AX）

### 2.1 标签 chip —— 几乎全对

| 参数 | 真 One AX | 我方 `tagFlow` | 差 |
|---|---|---|---|
| 行内步长 | **58.0** | `58.33 * sx` | +0.33 ✓ |
| chip 间隙 | **8.0** | `8.33 * sx` | +0.33 ✓ |
| chip 最小宽 | **50.0** | `minWidth: 50 * sx` | 0 ✓ |
| 行间间距 | 44（AX 热区）| `13.66 * sy` | 视觉高度不同口径 |
| AX 报 h | 44 | 视觉 29.667 | 44 是**热区**，29.667 是视觉 |

**结论：`tagFlow` 参数来自逐像素实测，与真机一致。此前的「纯文本」判断作废。**

### 2.2 右栏内边距 —— 真实差异在这里

```
真 One AX：
  所有右栏内容 x = 523.0（与右栏容器起点**同 x**）→ 左内边距 = 0
  最右内容边界 = 850.7 → 右留白 = 100.3pt
  内容实际占用 = 850.7 - 523.0 = 327.7pt

我方 detailColumn：
  pad = 16               → 内容从 428 内部 16pt 处开始
  trailing = 92（横持）  → innerW = 428 - 16 - 92 = 320
  ⇒ 内容 x = 523 + 16 = 539（比真机右移 16pt）
  ⇒ 内容宽 320（真机 327.7，差 7.7pt）
```

**差异：左内边距多 16pt，可用宽少 7.7pt。**

### 2.3 继续播放 —— 结构确实不同

| 项 | 真 One | 我方（横持） |
|---|---|---|
| 形态 | **实体按钮 168×52** | 纯文本行 `play.fill + "继续播放"`，`frame(height: 20)` |
| AX 高度 | **52.0** | 20（文本行）|
| 宽度 | **168.0** | 未限宽 |

**这是唯一「结构级」的真实差异。**

### 2.4 统计行 —— 真缺

```
真 One：1215k 次观看 · 收藏 16k · 评论 23    (523, 168.6, 188×14.3)
我方：  「共 N 集」                          (仅集数)
```
**我方没有「观看数/收藏数/评论数」，这是数据层缺失，不只是布局。**

### 2.5 元信息行 —— 内容不同

```
真 One：2026-11-03 · 人间杀妈客 · ♥ 14k    (523, 146.3, 182×14.3)
我方：  year · remarks                      (年份 · 备注)
```
**结构相同（一行 14pt），内容字段不同。**

## 三、真实差距排序（按影响）

| 优先 | 差距 | 类型 | 改动量 |
|---|---|---|---|
| **1** | 继续播放：文本行 → **168×52 实体按钮** | 结构 | 中 |
| **2** | 统计行缺「观看/收藏/评论」 | 数据+布局 | 小（需数据源） |
| **3** | 左内边距 16 → **0**，trailing 92 → **100** | 参数 | 极小 |
| 4 | 元信息行字段换成「日期·作者·点赞」 | 内容 | 小 |

## 四、可直接改的两项（参数级）

```swift
// 当前
let pad: CGFloat = 16
let trailing: CGFloat = landscape ? 92 : 16

// 应改为（对齐 AX 实测）
let pad: CGFloat = landscape ? 0 : 16      // 横持: 真机内容与容器同 x
let trailing: CGFloat = landscape ? 100 : 16  // 真机右留白 100.3
```

**验算**：`innerW = 428 - 0 - 100 = 328`，与真机「内容占用 327.7」**吻合到 0.3pt**。
