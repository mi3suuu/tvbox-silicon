## 二、★ 关键发现：此前所有坐标验证都在全屏态下做的

**根因链**（本次首次查清）：
```
1. @AppStorage("watchFullScreen") 持久化值 = true
   → 每次进播放页直接全屏，右栏根本不渲染
2. autoFullScreen 默认 true
   → onChange(of: playing) → guard value, autoFullScreen, !fullScreenNow → onFullScreen()
   → 开播后自动再进全屏
```

**第一次成功进入双栏的证据**：
```
FSPROBE onAppear isFullScreen=false -> false
pictureColumn col=522x635 fs=false win=475x267 at=(16,143)
```

**⇒ 必须同时关掉 `watchFullScreen` 和 `oneSkinAutoFullScreen` 才能稳定停留双栏。**
（修改方法：终止 App → `killall -9 cfprefsd` → 改容器 plist → 启动；容器 UUID 每次重装会变，必须用 `apps.list` 的 `data_path` 现查。）

## 五、不可直接比的项（性质不同）


（`OneSkinWindowGeometry.swift:186` 打 `view= / fixed= / layer= / videoRect=`）。
